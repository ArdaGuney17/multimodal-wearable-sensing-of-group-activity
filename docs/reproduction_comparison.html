No row here is bit-exact, but the ranking reproduces correctly — Transformer+sensors is the strongest model in both the paper and this run, exactly as the thesis reports. The gaps (1–4 points) are ordinary neural-training variance: PyTorch's seed doesn't pin every source of nondeterminism (dropout draws, BLAS thread scheduling), so a 3-seed average shifts a little run to run. The Segment Markov row, which has no such randomness, is off by only 0.002 — and the source notebook's own saved output matches this repo's number exactly, suggesting the published text figure (0.481) is itself the rounded one.
